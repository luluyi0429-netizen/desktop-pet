# 素材导入

正常运行只读取 assets/manifest.json 和 assets/audio/voices/manifest.json 中列出的文件。原图与原始录音不需要跟随程序。

## 图片

原图目录命名：1站立.png；闭眼.png、点击.png、提起.png、落地.png（可以附数字）；睡觉1.png、睡觉2.png；爬.png、爬2.png；左走/1.png、2.png……及右走/1.png、2.png……。

可选特殊素材：老吴.png、老吴.aac、哦鲸鲸？.png。

先备份 assets，再显式导入（替换示例目录）：

    npm run import:images -- D:/MyMaterials/Images

原来的“新建文件夹”和旧图片已移到项目外整理备份，不再启动时自动复制。

## 语音

    npm run import:voices -- D:/MyMaterials/Voices

支持 mp3、wav、aac、ogg、m4a，按 voice-library.cjs 的 GROUPS 文件名前缀分组。文件名中的中文用作字幕；——后面的语气备注不显示。导入后重启。

导入会覆盖对应打包文件，请先备份。不再自动扫描项目旁的“桌宠语音”；外部原始语音目录未被删除。

清单保留 34 段语音，包含 3 段尚未接入动作的备用配音，以免后续调整丢失。

导入后执行 npm run check 检查路径和缺失素材。只有确认不再引用的缓存文件才可删除。
