# 0.3.0 更新与使用

## 启动新版本

先从旧版托盘退出桌宠。源码版双击“启动桌宠.bat”；免安装版将新 ZIP 完整解压后运行“桌宠.exe”。

## 中日配音

设置面板新增“中文 / 日本語”按钮和“导入配音文件夹”。录音按 [中日配音台词](中日配音台词.md) 命名，例如 click_zh_01.wav、click_ja_01.wav；导入会保留旧音频。支持 wav、mp3、aac、ogg、m4a。

此版本提供台词与接入功能，尚未生成新增录音。某语言某场景未配音时沿用旧音频，不会自动翻译声音。日语录音也显示中文字幕。导入写入当前程序资源目录，更新免安装版时请重新导入原始录音。

“老吴”按钮改名为“神秘小按钮”。5 分钟内第三次叫醒，以及连续快速点击 15 次，特殊音效可以替换当前语音并跳过冷却，仍遵守静音与零音量，不叠加播放。

## 固定坐姿

标签工作台打开且与桌宠配对后，角色默认居中坐在上沿。使用新增五帧坐姿，不再自动散步或睡觉；工作台移动时跟随，切到文本助手不会掉下来。

取消“固定坐在标签工作台顶部”可恢复普通活动；拖动或手动攀爬仍可临时离开。关闭/收起工作台、切到不显示工作台的标签页、关闭/最小化浏览器或联动断开，会安全回落。工作台顶部须留出角色空间。

## 翻译与标签过滤

右键“选中文本”，或用 Ctrl+Alt+T / Ctrl+Alt+V。右上角“已置顶 / 置顶”控制面板是否始终显示在普通窗口上方，设置保存，桌宠保持独立置顶。

保留“翻译成中文”，取消解释与摘要。新增“标签过滤”，本地运行，无需 API：

- LoRA / 模型标记：识别模型标记，默认不勾选，可手动保留。
- 质量词、角色外貌、提示词字段、提示词自然语句：按组或逐项勾选；可调整分类。
- 权重括号中的逗号不拆开，自然语句尽量保持完整。规则分类不等同语义理解，特殊写法可手动调整。
- 可补充提示词，选择正向/负面及类别。
- “复制正向 / 复制负面”独立输出，复制全部时带正负标题。
- 原文可包含 Positive prompt: / Negative prompt: 标题。只有点击翻译时才向已配置接口发送原文。

面板上方提供 Civitai 与 Danbooru 快捷入口。

## 浏览器脚本必须更新

在 Tampermonkey 打开原 Danbooru Tag Tool，将内容全部替换为 browser/danbooru-tag-tool.user.js 后保存并刷新两个网站。保留原脚本名称和 namespace，避免重复安装。

脚本 v4 同时支持 danbooru.donmai.us 与 civitai.red。原自定义标签、过滤设置和复制历史继续使用；两个站点的数据分别保存在各自站点存储中。

Civitai 打开单张图片详情页，展开 Generation data。工作台“正向提示词 / 负面提示词”切换后，筛选、原始复制、自定义合并和记录均按当前方向工作。未公开参数的图片无法读取；可在文本面板粘贴已复制的参数再过滤。切图时清除旧结果，避免把上一张提示词当成新图。

提示未配对时重新粘贴桌宠配对码。浏览联动只使用当前正向提示词中的短标签，负面词不触发浏览反应。

成人标签继续共用语音池。精确生殖器标签给“哦鲸鲸”额外 20% 抽取机会；不连续播放两次，其他声音仍轮换。复制优先与语音冷却保持生效。
