# 0.4.2 点击卡住修复

修复鼠标捕获丢失后角色仍保持“按住”状态、停止活动且后续操作异常的问题。

- 不再每秒重复执行原生置顶操作。前台窗口变化或置顶属性丢失时才恢复；按住角色、操作设置和播放视频期间延后恢复。
- 窗口辅助进程提供鼠标主键按住状态。丢失松手事件时，只使用本次按住之后的新采样恢复；不会因固定超时打断真实长按，也不会用鼠标状态结束触屏或笔输入。
- 补齐捕获丢失、取消、失焦、重新点击的状态清理，并同步主进程与界面。移动后丢失松手事件会恢复下落；恢复动作不额外触发点击语音。
- 保留任务栏活动、坐姿、置顶、标签和已有语音设置。

先在托盘退出旧版，再启动新版。源码版运行“启动桌宠.bat”；免安装版完整解压 desktop-pet-0.4.2-win-x64.zip，双击“桌宠.exe”。同时运行时可能只找回旧实例，因此先退出旧版很重要。
