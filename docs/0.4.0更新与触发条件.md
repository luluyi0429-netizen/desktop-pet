# 0.4.0 更新与触发条件

## 启动

退出旧版后，源码版双击“启动桌宠.bat”；免安装版完整解压 desktop-pet-0.4.0-win-x64.zip，双击“桌宠.exe”。不会自动修改正在运行的旧进程，也不替换个人配置。

## 任务栏活动

取消标签工作台自动停靠、固定坐姿及相关设置。旧配置中的固定坐姿也会失效。角色默认在任务栏活动，保留原有散步、眨眼、90 秒未互动睡觉、拖拽与文件管理器攀爬。标签浏览/复制只显示字幕与播放语音，不再把角色反复切成点击姿势。坐姿素材保留，但不会自动播放。

## 配音导入

当前语音库 77 段，其中新增 43 段，另保留神秘小按钮音效。导入支持递归读取 zh、ja 及其子目录，识别“中文描述 + click_zh_01”等后缀，保留同场景多份不同录音。中文描述用作中文字幕；日语音频也使用中文字幕。

右键 → 语音设置 → 中文 / 日本語。优先播放选中语言；该场景缺少新配音时，普通场景沿用旧日语录音。条件专用语音只在有对应语言素材时播放。分时问候当前仅有日语版本。sit 与 annoyed 录音已收录备用；本版取消自动坐姿，第三次叫醒仍使用神秘音效。

所有自动语音遵守静音、音量、全局语音冷却；不叠加播放。新概率和时间常量集中在 conditional-voices.cjs，便于后续调整。

| 场景 | 当前规则 |
| --- | --- |
| 启动问候（日语） | 每次启动一次；电脑本地时间 05:00–10:59 早上、11:00–17:59 中午、18:00–22:59 晚上、23:00–04:59 深夜。系统开机后需启动桌宠；没有新增开机自启。 |
| 连续点击（日语） | 4 秒内 5 次有效点击，独立冷却 30 秒；忙时只保留一次，等待当前语音及冷却结束，最长 95 秒。拖拽、睡觉、静音或特殊 15 连点会清除等待。 |
| 胸前点击 | 站立、眨眼和四种点击姿势支持胸前热区，随大小缩放；35% 概率播放对应语言专用录音，否则沿用固定“别一直戳”录音。拖拽不计作点击，睡觉优先叫醒。 |
| 中文胸前后续 | 前置中文专用语音成功开始后 60 秒内再次点中，50% 概率触发后续吐槽；一次后消耗前置条件。仍须等全局冷却，不会两句同时播放。 |
| 拖拽（中文） | 30% 概率专用录音，独立冷却 60 秒；否则普通拖拽语音。 |
| 下落（中文） | 下落距离超过 36 逻辑像素时尝试播放“能飞”语音。设置新增“下落时播放语音”开关；已有语音或冷却中则跳过。 |
| 闲置（日语） | 清醒待机每 30 秒检查一次，15% 概率触发专用闲聊，独立冷却 180 秒。 |
| 晚间闲聊（日语） | 18:00–22:59 的待机检查中，15% 概率播放月色语音，独立冷却 180 秒。 |
| 重复标签（中文） | 5 分钟窗口中连续 3 张不同图片的完整正向标签集合相同，35% 概率吐槽，独立冷却 60 秒。刷新同一图片、复制、负面标签不计数。 |
| 连续成人标签（中文） | 5 分钟窗口中连续浏览至少 3 张带成人标签的不同图片时触发，独立冷却 60 秒；普通图片打断连续次数。复制优先、静音、规则开关继续有效。 |

## 暴怒视频

右键面板“神秘小按钮”旁边新增“暴怒 ▶”，托盘也有入口。打开内置视频窗口播放用户提供的 MP4，已转换为 H.264/AAC 并保存到 assets/video/rage.mp4，免安装版不依赖桌面的原文件。原始桌面视频未修改。

窗口置顶，可拖动、缩放、暂停和拖进度；Esc 或“关闭”立即结束，播放完成自动关闭。反复点按钮只找回已有窗口，不会同时打开多个。视频初始音量跟随桌宠设置，桌宠静音/零音量也约束视频。播放期间暂停角色活动与语音，关闭后恢复。
