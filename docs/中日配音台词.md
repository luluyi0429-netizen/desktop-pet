# 中日配音台词

每句分别导出音频，支持 wav / mp3 / aac / ogg / m4a。整体慵懒自然，睡醒略带困意。设置 → 导入配音文件夹，再选择中文或日本語。未补录场景保留旧声音，字幕保持中文。

annoyed 配音为备用；第三次叫醒仍播放原有特殊音效。

touchChest 为胸前点击区域的固定配音；未导入时使用已有“真是的，别一直戳啦！”录音。可按上述文件名分别录制中文、日语，再在设置中导入。区域点击遵守语音冷却、静音和音量，不会同时播放普通点击语音。
