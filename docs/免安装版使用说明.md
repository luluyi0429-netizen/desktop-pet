# 桌宠 · Windows 免安装版

本版更新见 [0.4.4 语音与坐姿精简](0.4.4语音与坐姿精简.md)：取消中文切换，仅保留“中国人能飞”掉落语音；保留三张坐姿。其他配音仍为日语，字幕仍为中文。历史文档中的中日切换及五张坐姿说明已被本版替代。

## 运行

1. 支持 Windows 10/11 的 64 位 x64 电脑。不支持 Windows 7、32 位 Windows、macOS 或 Linux。
2. 下载 ZIP，右键选择“全部解压”。请解压整个文件夹，不要直接在压缩包里运行。
3. 双击文件夹里的“桌宠.exe”。不需要安装 Node.js、npm 或 Python，也不需要管理员权限。
4. 保留同目录 DLL、resources、locales 等文件，不能单独复制 EXE。程序使用系统自带的 Windows PowerShell 做窗口检测。
5. 如果旧版桌宠正在运行，先从托盘菜单“退出桌宠”，再启动此版本；同一用户只运行一个实例。

这是“解压即用版”，不是单文件 EXE。配置仍保存在当前用户的 %APPDATA%/desktop-pet-prototype，不写在安装目录。移动文件夹不会丢失本机配置，但换电脑不会自动带走旧配置。

## 操作

- 左键点击互动，按住拖动，右键打开设置。
- 面板可调大小、音量、说话频率、语音冷却、静音，以及睡觉、神秘小按钮、暴怒视频、爬上窗口。
- 托盘双击找回角色；右键“退出桌宠”结束程序。直接关闭主体也会同时清理字幕和后台服务。
- 攀爬支持文件资源管理器窗口；顶部需留出角色站立空间，最大化时请先还原并下移窗口。

## 标签联动

在浏览器安装 Tampermonkey 或兼容扩展，创建脚本并粘贴 browser/danbooru-tag-tool.user.js 的完整内容保存。
在桌宠标签设置中复制配对码，粘贴到网页工作台的“桌宠联动”。不要向别人分享配对码。
联动服务仅监听本机 127.0.0.1:17861。下载者首次运行会生成自己的配置和配对信息，压缩包不携带制作者的个人配置。

## 选中文本：翻译与标签过滤

1. 右键桌宠 → 选中文本… → AI 接口设置。填写 API 地址、模型名称与密钥，然后保存。
2. 支持兼容 Chat Completions 的接口。地址可用服务商给出的带版本路径 Base URL，或完整 /chat/completions 地址。远程接口需 HTTPS，本机接口允许 HTTP。更换地址后请重新填写密钥。
3. 在其他应用中选中文字，按 Ctrl+Alt+T。未读取到选区时，先 Ctrl+C，再按 Ctrl+Alt+V；也可手动粘贴到面板。
4. 选择翻译成中文或标签过滤，确认发送目标后点击“开始处理”。不会仅因选中、复制或打开面板就发送内容。
5. 结果可复制；等待期间可取消。最多 8000 字符，60 秒超时。关闭面板清空本次原文和结果，不保留处理历史。

API 密钥使用 Windows 用户加密机制保存，不包含在发行包中；换电脑需重新配置。请使用自己的模型和密钥，服务商可能计费。快捷键被其他应用占用时，面板会提示，可使用手动粘贴。部分应用不提供选区接口，请使用复制入口。当前只显示结果文字，不启用系统朗读。

## 卸载与排错

- 先退出桌宠，再删除解压文件夹，即可移除程序。设置不会自动删除；如需彻底清除，可自行备份后删除上述 AppData 子目录。
- 若没有看到角色，检查系统托盘，双击图标找回。
- 确认完整解压，目录里的 DLL 和 resources 未被移动，系统安全软件没有隔离文件。
- 这是未单独进行应用代码签名的打包版本，Windows 可能提示“未知发布者”或 SmartScreen。先确认下载来源和 SHA-256，不要关闭系统安全防护。
- 不要把整个压缩包放进 Git 仓库。应上传到 GitHub Releases 的附件区域，源码通过正常提交更新。
