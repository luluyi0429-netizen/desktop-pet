# Windows 桌面交互助手

基于 Electron 的 Windows 桌面交互应用，整合透明角色动画、窗口边框攀爬、本地语音、网页标签工作台及选中文本处理。

本文适用于 **0.4.0-custom.2 / Windows x64**，整理日期为 **2026-10-14**。这是以 0.4.0 为底版的独立修改版，不是备份开发版本 0.4.4 的继续升级。包内旧版文档中关于中日切换、自动坐姿和特定标签语音概率的描述，以本文为准。

> 当前为个人整合版。功能与包完整性检查通过，但不代表已完成公开发布审查。公开发布前还需解决素材授权、公开发布内容及旧运行时问题，详见后文。

## 快速开始

### 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11，x64 |
| 桌面运行环境 | 包内自带 Electron 32.2.0 |
| 系统组件 | Windows PowerShell，用于窗口检测和选区读取 |
| 免安装版额外依赖 | 不需要自行安装 Node.js、npm 或 Python |
| 浏览器联动 | Chrome / Edge 等支持用户脚本扩展的浏览器 |
| 联网要求 | 本地角色、配音和标签过滤可离线；网页访问及远程翻译需要网络 |

未对 Windows ARM、Windows 7、macOS 或 Linux 提供验证支持。

### 启动步骤

1. 先退出正在运行的旧版：系统托盘中右键桌宠图标，选择退出。
2. 下载发行 ZIP，右键选择“全部解压”。
3. 打开解压后的文件夹，双击 **桌宠.exe**。
4. 看不到角色时，在任务栏右下角展开隐藏图标，双击桌宠托盘图标找回。
5. 右键角色，打开设置面板。

必须完整解压，不能在压缩包中运行，也不能只复制 EXE。DLL、resources、locales 等运行文件需与 EXE 保持原有目录关系。

这是“解压即用版”，不是单文件程序。通常无需管理员权限。配置保存在当前用户 AppData，移动程序文件夹不会重置设置。

### 升级与卸载

- 升级：退出旧版，将新版解压到独立文件夹，再启动新版；不要混合覆盖不同版本的运行文件。
- 卸载：退出程序后删除解压文件夹即可。
- 清除个人设置：备份后自行删除 %APPDATA%\desktop-pet-prototype。此操作也会清除配对信息与 AI 接口设置，需要重新配置。

## 操作与功能

| 操作 | 效果 |
|---|---|
| 左键点击角色 | 点击反应；满足条件时播放本地语音 |
| 按住并拖动 | 移动角色；松手后下落或停靠窗口边框 |
| 右键角色 | 打开大小、音量、行为及功能设置 |
| 托盘双击 | 找回角色 |
| 托盘右键 | 显示、隐藏、功能入口及退出 |
| Ctrl+Alt+T | 读取前台应用选中文字，打开文本面板 |
| Ctrl+Alt+V | 主动读取剪贴板文字，打开文本面板 |

### 右键面板

- 大小：50%～200%。
- 自动散步 / 攀爬：可开启或关闭。
- 动作：站立、睡觉、爬上窗口、站到任务栏。
- 声音：静音、0%～100% 音量、少说 / 标准 / 多说、1～60 秒语音冷却。
- 下落语音：可单独开关“中国人能飞”。
- 神秘小按钮：播放原有声音和动作，不显示“神秘嘉宾登场”。
- 暴怒：打开视频窗口，取消标题文案和说明框；视频播放完自动关闭，可按 Esc 或悬浮关闭按钮退出。
- 标签联动：配置网页事件规则和配对信息。
- 选中文本：打开翻译 / 标签过滤面板。
- 一键传送：Civitai 与 Danbooru 两个网站入口，没有向上箭头。

右键面板在较小屏幕上可滚动，“一键传送”位于面板靠下位置。

### 行为与睡眠

- 角色默认在任务栏上方活动，不固定在网页标签工作台上。
- 行走速度为 45 DIP/秒，休息间隔约 18～32 秒，单次行走约 6～10 秒。
- 约 5 分钟未互动、且不处于阻止入睡的忙碌状态时进入睡眠。
- 睡满 2 分钟自动醒来，重新开始计算待机时间，不会立刻再次入睡。
- 点击可提前叫醒；自然醒不计入连续叫醒次数，也没有额外强制播放叫醒语音。
- 5 分钟内第三次点击叫醒触发神秘互动。
- 连续点击 15 次、相邻点击间隔不超过 1 秒，可触发神秘音频。
- 此版本沿用 0.4.0 的行为，没有合入 0.4.4 的自动坐姿循环。素材清单内有 5 张坐姿，但存在素材不代表已接入自动动作。

### 窗口停靠与攀爬

目前针对 **Windows 文件资源管理器窗口**，不是任意网页中的边框。

1. 打开一个未最大化的文件资源管理器窗口。
2. 窗口顶部留出足够放下角色的空间。
3. 将角色脚部拖到窗口上沿或内部下沿附近后松手，可停靠。
4. 点击“爬上窗口”，角色会寻找合适窗口，靠近侧边、向上爬并翻上顶部。
5. 窗口移动时角色跟随；窗口消失或最小化时角色回落。

若提示没有合适窗口，先还原窗口、向下移动、将角色移到同一显示器，或减小角色大小。

## 浏览器标签工作台

### 支持网站

- [Danbooru](https://danbooru.donmai.us/)
- [Civitai 镜像站](https://civitai.red/)

脚本匹配上述域名。其他域名或网站改版不保证兼容；Civitai 原站不在此版本脚本的匹配列表中。

### 安装脚本

1. 在浏览器安装 Tampermonkey 或兼容的用户脚本扩展。
2. 打开扩展管理面板，选择新建脚本。
3. 用文本编辑器打开包内 browser/danbooru-tag-tool.user.js。
4. 将文件完整内容替换到新脚本中，保存并启用。
5. 如果浏览器提示缺少“允许用户脚本”权限，进入扩展详情页开启对应权限。
6. 刷新支持的网站，进入图片详情页面，打开标签工作台。

这是用户脚本文件，不是普通网页。不要只在文件管理器里双击后认为已经安装。

### 配对桌宠

1. 启动桌宠。
2. 右键角色 → 标签联动 → 复制配对码。
3. 在网页标签工作台的“桌宠联动”中粘贴配对码并保存。
4. 浏览其他图片或执行工作台复制操作，检查联动反应。

配对码是本机认证信息，不要放到 README、截图、视频演示或公开仓库中。服务只监听 127.0.0.1:17861。

### 标签处理

- Danbooru：读取图片标签，可筛选、复制，并使用工作台标签页与复制记录。
- Civitai：读取可见图片提示词，区分正向与负面提示词，分别处理和复制。
- LoRA / 模型标记、质量词、角色外貌、提示词字段、自然语句可分类筛选。
- 没有公开提示词的图片、未加载完成的数据或网站结构变化可能导致读取不到内容。
- 工作台的普通复制记录由浏览器用户脚本存储管理，不随桌面程序包分发。

### 联动规则

默认标签规则概率为 100%，默认标签冷却为 5 秒。实际是否发声还取决于静音、音量、说话频率、语音冷却以及角色是否忙碌。

浏览事件与复制事件分开计时；复制反应优先排队，不与正在播放的语音叠加。网页工作台的复制操作和系统 Ctrl+C 检测可产生复制事件，但不承诺识别所有第三方软件内部的复制按钮。

可在标签设置面板关闭某类规则或整个标签联动。

## 翻译与标签过滤

### 读取文字

- 选中文字后按 Ctrl+Alt+T：尝试通过 Windows 辅助功能接口读取选区。
- 读取失败时，先手动 Ctrl+C，再按 Ctrl+Alt+V。
- 也可以在文本面板直接粘贴。

读取选区不会模拟 Ctrl+C，也不会覆盖原剪贴板。普通复制、选中文字和打开面板本身不会自动向 AI 服务发送文字。

### 翻译接口配置

1. 打开选中文本面板，展开“AI 接口设置”。
2. 填写服务商提供的 API 地址、模型 ID 和密钥。
3. 支持兼容 Chat Completions 的接口；地址可使用包含版本路径的 Base URL，或完整 /chat/completions 地址。
4. 远程接口使用 HTTPS，本机接口允许 HTTP。
5. 保存设置，选择“翻译成中文”，再点击“开始处理”。

接口地址改变后需重新填写密钥。最多处理 8000 字符，翻译请求超时为 60 秒。服务商可能收费，本程序没有附送模型额度。

### 本地标签过滤

标签过滤在本机完成，不需要 AI API，也不会将提示词发送给模型。

| 分类 | 作用 |
|---|---|
| LoRA / 模型标记 | 单独识别如 <lora:...> 的字段，默认排除 |
| 质量词 | 质量、分辨率、画面细节等标签 |
| 角色外貌 | 发型、眼睛、肤色、身形等特征 |
| 提示词字段 | 其余标签式短语 |
| 提示词自然语句 | 描述画面的完整语句 |

用户可选择保留内容、调整分类、增加提示词，并分别复制正向与负面结果。分类采用规则，可能误分，应在复制前检查。

### 置顶与关闭

右上角“已置顶”可切换窗口是否保持在普通窗口上方。此设置不代表能覆盖独占全屏、系统安全桌面或所有高权限窗口。

关闭文本面板会取消本次请求并清除原文与结果。页面不再显示两个网站的快捷链接，网站入口在桌宠右键“一键传送”。

## 语音与触发规则

### 音频数量

当前语音清单包含 **63 段**：62 段日语及 1 段中文“中国人能飞”。此外保留独立的神秘音频 assets/audio/laowu.aac，共 64 个音频文件；暴怒视频单独存放。

这里“仅保留一段中文”指普通语音库，神秘彩蛋的原音和视频音轨未删除。日语录音显示中文字幕。运行时播放本地音频，不依赖系统朗读或 GPT-SoVITS 服务；配音训练在外部完成后导入音频，本包不包含训练模型或训练环境。

### 普通与交互语音

| 场景 | 触发方式 |
|---|---|
| 开机问候 | 按本地小时选择：5～10 点早间、11～17 点日间、18～22 点晚间、23～4 点深夜 |
| 点击 | 普通点击按语音门限随机播放 |
| 胸部区域互动 | 命中对应区域时，概率选择专用录音 |
| 重复点击 | 4 秒内达到 5 次，内置 30 秒冷却；仍受播放状态限制 |
| 睡觉 / 叫醒 | 入睡尝试播放睡觉录音；点击叫醒优先播放叫醒录音 |
| 拖动 / 下落 / 落地 | 在对应动作阶段尝试播放；下落彩蛋可单独关闭 |
| 行走 / 登顶 | 开始行走、攀爬到顶部时尝试播放 |
| 闲聊 | 根据说话频率周期尝试，另有低概率闲聊和晚间闲聊 |
| 复制 / 翻译 / 过滤 | 对应操作或结果事件产生语音请求 |
| 神秘小按钮 | 手动按钮、三次叫醒或快速点击满足条件时触发 |
| 暴怒 | 手动按钮播放视频 |

清单里保留了少量旧组，如 sit、annoyed、rapid、collect、cool；保留音频不代表每组都有当前可达的独立自动触发入口。

### H 标签语音池

此部分记录当前个人整合版的技术行为，不在发布文案中逐条展示露骨台词。

- 通用候选为 18 段，包括“哦鲸鲸”。
- 4 段条件语音已合并进同一 H 池，匹配条件后才进入候选。
- 全部条件同时成立时，共 22 段候选。
- 各候选同权重进入随机轮换袋；条件集合不变时，每轮每段出现一次。
- “哦鲸鲸”不再额外加权；条件语音不再单独执行 35% 判定或 60 秒冷却。
- 共用 H 标签事件规则及全局说话频率、语音冷却。
- 不同标签组合使用不同轮换袋，避免上一张图片的条件语音错误用于下一张。

| 条件 | 增加段数 | 当前精确匹配的标签示例及列表 |
|---|---:|---|
| 裸体 | 1 | nude、naked、nake、completely_nude |
| 插入 | 1 | penetration、vaginal、anal、insertion、deep_penetration |
| 射精 | 2 | cum、ejaculation、cum_in_mouth、cum_in_pussy、cum_in_ass、internal_cum、creampie |

后两段共享“射精”条件，没有进一步区分口内与体内场景。只有进入 H 规则且条件成立才可能选择，不是仅出现标签就立即播放。

“同享概率”指候选同权轮换，不是每次独立、有放回地随机抽取。具体一次的机会还取决于该轮已播放的内容；不会保证每次浏览都出声。

### 说话频率与冷却

| 设置 | 普通语音通过概率 | 普通闲聊尝试间隔 |
|---|---:|---:|
| 少说 | 30% | 6 分钟 |
| 标准 | 65% | 4 分钟 |
| 多说 | 100% | 2 分钟 |

默认多说，语音冷却默认 5 秒，可调 1～60 秒。通常在播放结束后重新计时；有正在播放的语音时不叠加。睡觉、叫醒等重要互动存在优先规则，不完全按普通语音概率处理。

导入新语音后，文件完整性校验会发生变化。若要再次分发，应重新打包并生成校验文件，不要沿用原发行包的 SHA-256。

## 数据与隐私

| 数据 | 位置 / 用途 |
|---|---|
| 桌宠偏好 | %APPDATA%\desktop-pet-prototype\settings.json |
| 标签规则 | 同目录 tag-link.json |
| 配对认证信息 | 同目录 tag-link-key.json |
| AI 接口配置 | 同目录 text-assistant.json；密钥使用 Electron safeStorage 加密保存 |
| 文本窗口置顶设置 | 同目录 text-panel.json |
| 工作台设置与记录 | 浏览器用户脚本存储 |

- 发行包不包含上述个人配置，不包含实际 API 密钥或配对码。
- 标签联动使用本机 HTTP 服务及配对认证，不上传图片给桌宠。
- 窗口辅助进程读取窗口几何信息和 Ctrl+C 状态；选区读取在用户主动操作时进行。
- 翻译内容发送给用户配置的 API 服务商，遵循该服务商的数据政策。
- 本地过滤无需网络。程序不保存文本面板的处理历史，但这不代表远程服务商不保留请求。
- 加密设置与当前 Windows 用户相关，不应把 AppData 配置当成跨电脑分享包。

## 常见问题

### 启动后没有角色

先检查是否已有旧实例；在托盘双击找回。确认完整解压、资源文件未缺失，并查看系统安全软件是否隔离了文件。不要通过关闭系统防护来跳过问题。

### 中文切换按钮不见了

本版已移除中文语言切换，普通语音固定日语。中文字幕继续保留，中文掉落彩蛋可单独关闭。

### 没有声音

检查桌宠静音、音量、Windows 音量混合器、正在播放的声音和语音冷却。频率设置与标签概率是不同的控制。不是每次操作都必定播放。

### H 条件语音仍然不出现

先确认网页事件成功配对、H 规则启用、标签实际匹配，再检查语音是否在冷却或角色是否睡觉 / 拖动 / 攀爬。四段条件录音不再优先插队，会与其他符合条件的语音同权轮换。

### 标签工作台不出现或无法配对

确认脚本启用、用户脚本权限打开、网址属于匹配域名，并刷新详情页。确认桌宠已启动且 17861 端口未被其他程序占用。换电脑后需要重新配对。

### 翻译报错

检查 API 地址、模型 ID、额度和密钥。更改服务商地址后重新保存密钥。选区读不到时使用手动复制；标签过滤无需 AI 接口。

### 角色无法盖住某些窗口

本版沿用 0.4.0 的窗口置顶机制，没有合入所有后续置顶修复。可通过托盘找回；独占全屏及系统安全桌面不保证覆盖。

### 3. 用 GitHub Desktop 上传源码

完成上一步后：

1. 在 GitHub Desktop 选择准备好的仓库 / 工作目录，确认分支正确。
2. 在 Changes 中逐项检查，不包含 node_modules、release、ZIP、EXE、DLL、个人配置、日志或 API 密钥。
3. 确认 README、源码、获授权的运行素材、浏览器脚本和必要构建测试文件在提交中。
4. 在 Summary 填写清楚的说明，例如“准备桌面交互助手公开测试版”。
5. 点击 Commit to 当前分支。
6. 点击 Push origin。若是新分支，界面可能显示 Publish branch。
7. 点击 Repository → View on GitHub，确认文件与分支已上传。

不要把打包文件上传到网页的 Add file → Upload files。当前 ZIP 约 144 MiB，EXE 约 178 MiB，均超过普通 Git 单文件 100 MiB 限制。程序 ZIP 应作为 Release 附件上传。

### 4. 创建 Release 草稿

准备好可分发、已验证的公开版后：

1. 打开仓库右侧 Releases，选择 Draft a new release / Create a new release。
2. Choose a tag：创建该公开版的新标签。当前个人版技术版本是 v0.4.0-custom.2，公开版改过内容时应使用新标签。
3. Target：选择第 2 步准备并验证过的分支 / 提交，不能随意选择旧 main。
4. Release title：填写实际版本，例如“桌面交互助手 · Windows x64 测试版”。
5. 在正文写清功能、安装方法、版本基线、限制和校验方式。
6. 在附件区域上传该版本的 ZIP 与同名 .zip.sha256，可额外上传 README。
7. 首次分享建议勾选 This is a pre-release。
8. 先点击 Save draft，检查附件是否上传完整、标签和 Target 是否正确。

注意：GitHub 自动生成的 Source code (zip / tar.gz) 是标签对应的源码，不是免安装程序。用户应下载你手动上传的 Windows ZIP 附件。

### 5. 发布并复核

1. 完成内容、许可证及功能检查后，点击 Publish release。
2. 从发布页面重新下载 ZIP，在新的目录完整解压。
3. 对比 .sha256，检查启动、角色、声音、标签和退出。
4. 未登录或其他账号打开链接，确认实际访问权限。私有仓库的 Release 不会因为发布而自动变成公开下载。

要让任何人访问，需要仓库公开；改变可见性之前还要检查历史提交中的素材和敏感信息，不只是最新文件。不要将“仓库公开”与“已经获得开源授权”混为一谈。

### 6. 校验下载文件

在下载目录打开 PowerShell：

~~~powershell
Get-FileHash -LiteralPath ".\实际下载的文件名.zip" -Algorithm SHA256
~~~

将结果与同名 .sha256 文件的第一段十六进制字符串逐字对比，大小写不影响比较。每次修改说明、源码或素材并重新打包后，都应重新生成校验值。
