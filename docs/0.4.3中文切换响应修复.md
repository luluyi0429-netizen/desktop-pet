# 0.4.3 中文切换响应修复

针对“切换中文后角色停住，重新点击或打开设置又恢复”的反馈修正语言切换流程。

- 选择中文或日语后自动收起设置菜单。此前菜单保持打开时会暂停自动散步，切换后没有明显完成反馈。
- 实际改变语言时停止旧语言的当前语音、清除待播放的点击反应及旧冷却，下一次点击可立即使用新语言。普通语音仍使用原有冷却；点击已选语言不会反复清除冷却。
- 取消特殊语音时同步退出对应特殊姿势，避免语音停止而姿势一直保持。坐姿和睡姿不因语言切换被强制改成站姿。
- 旧语音延迟返回的结束事件不会取消新语音。
- 字幕已隐藏时不再每个动作帧重复调用原生隐藏窗口操作。
- 切换后短暂显示“已切换为中文语音”或“已切换为日语语音”；鼠标停在托盘图标上可看到版本号。

## 使用

1. 从托盘退出旧版本。
2. 完整解压 desktop-pet-0.4.3-win-x64.zip 到新文件夹，双击“桌宠.exe”。
3. 右键角色选择“中文”。菜单自动关闭后，点击角色应正常响应并使用中文配音。

保留已有音量、静音、语言、散步开关及联动配置。静音时不发声；关闭“自动散步 / 攀爬”时角色不会自动走动。坐姿可以保持静止，但仍可点击、拖动和触发语音。

## 验证

增加语言切换的逻辑回归与隔离实机测试，覆盖旧语音清理、首次中文点击、中日连续切换、坐姿交互、中文音频实际播放、拖动落地及切换后自动散步恢复。
