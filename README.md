# 桌面宠物

当前版本见 [0.4.4 语音与坐姿精简](docs/0.4.4语音与坐姿精简.md)：取消中文切换，仅保留“中国人能飞”掉落语音；坐姿只使用 1、2、3.png。历史更新文档中的中日切换及五张坐姿说明已被本版替代。

Windows 桌面宠物，基于 Electron。支持透明动画、文件管理器边框停靠、垂直攀爬、本地配音，以及浏览器标签工作台联动。

## 启动

**免安装版：** 下载 `desktop-pet-版本-win-x64.zip`，完整解压后双击其中的 **桌宠.exe**。使用者不需要安装 Node.js 或 npm，不要在压缩包内直接运行。详细步骤见 [免安装版使用说明](docs/免安装版使用说明.md)。

### 从源码启动

需要 Windows 10/11、64 位 Node.js 20 或更新版本、npm 和系统自带的 Windows PowerShell。

已安装依赖时双击 **启动桌宠.bat**。首次下载源码，在项目目录执行：

    npm ci
    npm start

node_modules 是本机运行依赖，不上传 GitHub；下载源码后重新安装即可。直接打开 HTML 不会启动桌宠。

## 使用

- **左键**：随机点击反应；按住拖动，松开后缓降或停靠窗口边框。
- **右键**：大小、音量、静音、说话频率、语音冷却、睡觉、神秘小按钮、暴怒视频、爬上窗口、标签联动和退出。
- **托盘**：双击找回桌宠；右键可隐藏、显示或退出。关闭主窗口会同时关闭字幕及后台服务。
- 约 1 分钟未互动坐下，3 个坐姿每个保持 45～75 秒，坐下仍可触发语音；5 分钟未互动会睡觉。点击叫醒优先播放睡醒语音；5 分钟内第三次叫醒触发老吴。连续快速点击 15 次也可触发老吴语音。
- 右键“一键传送”打开 Civitai 或 Danbooru；选中文本页面不再提供网站按钮。
- 所有配音为本地音频，配有中文字幕，不使用系统朗读。

### 窗口停靠与攀爬

支持 Windows 文件资源管理器窗口。把角色脚部拖到窗口上沿或内部下沿附近，松手即可停靠。窗口移动时角色跟随，关闭或最小化时角色回落。

手动“爬上窗口”会寻找同一显示器内合适的窗口：走到侧边，必要时跳起抓边，向上爬并翻上顶部。标签工作台不会影响角色位置。自动攀爬仍保留近距离和可触碰条件。

**窗口顶端必须留出能放下整个角色的空间。** 如果提示顶部空间不足，请取消最大化并下移窗口，或缩小桌宠。

### 标签联动

1. 在浏览器安装 Tampermonkey 或兼容扩展。
2. 创建用户脚本，粘贴 browser/danbooru-tag-tool.user.js 的完整内容并保存。脚本同时匹配 Danbooru 与 civitai.red。
3. 桌宠右键 → 标签联动 → 复制配对码，在网页标签工作台的“桌宠联动”中粘贴。
4. 浏览或复制标签触发反应；角色默认在任务栏活动，不再停靠标签工作台。

成人标签统一归类，语音池轮换，不再由单个标签独占优先级。复制提示与浏览分开计时，等待当前语音和冷却结束，不叠加播放。规则可在面板中编辑或关闭。默认概率 100%、标签冷却 5 秒；语音冷却另行设置。

### 选中文本交互（v0.3.0）

1. 桌宠右键或托盘 → **选中文本…** → 展开 **AI 接口设置**。
2. 填写兼容 Chat Completions 的 API 地址、模型 ID 和密钥，点击 **保存接口设置**。可填带版本路径的 Base URL 或完整的 /chat/completions 地址；HTTPS 远程接口和本机 HTTP 接口均可。地址变化时原密钥会被清除，需重新填写。
3. 在其他应用选中文字后按 **Ctrl+Alt+T**。Windows UI Automation 读取当前前台控件的选区，不会模拟 Ctrl+C，也不覆盖剪贴板。
4. 若应用不支持选区读取，先 **Ctrl+C**，再按 **Ctrl+Alt+V**；或打开面板点击 **读取剪贴板**、直接粘贴。普通 Ctrl+C 不会自动发送文字。
5. 选择 **翻译成中文 / 标签过滤**，再点击 **开始处理**。翻译发送到已配置接口；过滤在本机完成，无需 API。输入最多 8000 字符，翻译接口等待最多 60 秒。窗口右上角可切换置顶。

密钥通过 Electron safeStorage 加密保存在当前 Windows 用户的 AppData 配置目录，主进程解密并发起请求，不回传已保存密钥给界面；个人设置不进入发行包。关闭面板会清空本次文字并取消请求，不记录选区或结果历史。快捷键冲突时面板会提示，可使用手动粘贴入口。当前结果仅显示文字，保留已有本地配音，不启用系统朗读。

选区读取依赖应用暴露的辅助功能接口；浏览器、PDF 阅读器及管理员窗口可能不支持，使用手动复制入口即可。接口设置中的模型名称和密钥需要自行准备，服务商可能计费。

## 项目结构

- assets/：运行使用的动画、表情和音频（含清单）。
- browser/：可安装的浏览器配套用户脚本。
- docs/：素材导入及发布说明。
- scripts/：项目检查、测试入口、浏览器脚本构建。
- tests/：自动回归测试；以 -live 结尾的测试需手动运行。
- 根目录代码及页面：Electron 主进程、动作、联动、桌宠、字幕和设置界面。

启动直接使用 assets，**不依赖特定用户名、桌面目录或原稿文件夹**。更换素材见 [素材导入](docs/素材导入.md)。

## 开发与测试

    npm run check
    npm test
    npm run build:browser

npm test 只运行模拟/本地逻辑测试，不操控桌面窗口、不读取个人配对码。修改 browser-tag-link.js 后执行构建，再重新安装用户脚本。

手动实机测试：npm run test:shutdown。它会打开独立配置的测试桌宠与字幕，再关闭测试窗口；结果在 Git 忽略的 .local/。不会替换正式配置。菜单退出模式可先在 PowerShell 设置 $env:PET_SHUTDOWN_MODE='menu'。

## 隐私与发布

### 制作免安装包

在 Windows x64 上安装项目依赖后执行：

    npm run build:portable

构建会先运行项目检查和回归测试，再将本机已安装的 Electron 运行环境、程序和素材打包到 `release/desktop-pet-版本-win-x64.zip`，并生成 SHA-256 校验文件。`release/` 已被 Git 忽略，个人配置、配对码及开发依赖不会装入发布包。

可用 Node.js 22 或更新版本执行 `npm run test:portable`：从 ZIP 解压到包含中文和空格的路径，移除测试进程 PATH 中的 Node.js，用独立配置检查 EXE 启动、动画、音频、窗口监视和标签设置，随后关闭测试程序。测试结果保存在 `.local/`。

给其他人下载时，在 GitHub 仓库的 **Releases → Create a new release** 中附加 ZIP 和 `.sha256` 文件。免安装包超过 100 MiB，不要作为普通源码文件提交。私有仓库的 Release 仍需要仓库访问权限。

### 配置与素材

- 用户设置和配对密钥保存于 %APPDATA%/desktop-pet-prototype，不在仓库中。勿上传该目录、配对码、日志或浏览记录。
- 联动只监听 127.0.0.1:17861，以配对密钥验证消息；接收标签及工作台位置，不传图片。
- Windows 辅助进程读取可见窗口几何及 Ctrl+C 按键状态，不读取文件内容；退出时自动停止。
- 图片、声音和表情包的公开分发许可尚未核验，未擅自选择开源许可证。
- 当前固定依赖属于较早的 Electron 32 系列。公开发布前建议升级受支持版本、审查依赖安全并重新回归；本次未静默升级运行时。

上传前请阅读 [GitHub 发布检查清单](docs/GitHub发布检查清单.md)。
