# Windows 桌面交互助手

基于 Electron 的 Windows 桌面交互应用，支持透明角色动画、文件资源管理器边框攀爬、本地配音、浏览器标签工作台和选中文本翻译 / 标签过滤。

当前分支版本为 **0.4.0-custom.2**，以 0.4.0 免安装包为基线整理。原开发版本已保存在备份提交 b438f5d；本分支不包含后续版本的自动坐姿轮换、输入恢复或置顶恢复改动。源码及浏览器脚本通过 SHA-256 与 custom.2 原包逐文件核对。

完整操作、语音触发条件与发布教程见 [custom.2 完整说明](docs/custom.2完整说明.md)。构建与测试范围见 [源码与验证](docs/custom.2源码与验证.md)。这是个人整合版，素材授权与公开发布内容仍待整理。

## 免安装启动

Windows 10 / 11 x64：完整解压 Windows ZIP，双击“桌宠.exe”。保留 DLL、resources、locales 等所有文件，不要只复制 EXE 或在压缩包中运行。无需安装 Node.js、npm 或 Python。运行前退出旧实例。

详细说明见 [免安装版使用说明](docs/免安装版使用说明.md)。配置存放于当前用户的 %APPDATA%/desktop-pet-prototype，首次使用需要自行配对浏览器、配置 AI 接口。

## 操作与当前行为

- 左键互动，按住拖动；右键设置大小、音量、静音、说话频率、语音冷却及其他功能。
- 默认在任务栏活动；可停靠、攀爬文件资源管理器窗口，不会固定到网页标签工作台。
- 5 分钟无互动进入睡眠，睡眠 2 分钟后自然醒来；点击也可叫醒。没有自动坐姿轮换，素材中仍保留基线的 5 张坐姿图片。
- 5 分钟内第 3 次点击叫醒、连续快速点击 15 次，或点击“神秘小按钮”可触发彩蛋。神秘按钮没有登场字幕；“暴怒”仅播放视频。
- 62 段日语录音、1 段中文“中国人能飞”，另有独立彩蛋音频。日语配中文字幕，取消中日切换，不使用系统朗读。
- 成人标签共用一个语音池：18 段无附加条件，4 段满足对应标签条件后加入；候选等权轮换，共享概率及冷却。复制提示等待当前音频及冷却结束。
- 右键“一键传送”打开 Civitai 或 Danbooru；选中文本页没有网站按钮。
- 托盘双击找回角色，右键退出；退出会关闭字幕与后台服务。

## 浏览器标签工作台

1. 在浏览器安装 Tampermonkey 或兼容用户脚本扩展。
2. 创建脚本，复制 browser/danbooru-tag-tool.user.js 全部内容并保存。文件名沿用旧名称，脚本同时支持 Danbooru 与 civitai.red。
3. 桌宠右键 → 标签联动 → 复制配对码，在网页工作台的“桌宠联动”中粘贴。
4. 浏览、复制标签即可联动。Civitai 正向与负面提示词分开处理；具体提取结果取决于网页提供的数据。

本机服务监听 127.0.0.1:17861。配对码不要放入截图或仓库。网站结构变动可能使提取失效。

## 翻译与标签过滤

- Ctrl+Alt+T 读取前台应用选区；不支持选区读取时，先复制，再按 Ctrl+Alt+V，或手动粘贴。
- 翻译需在面板填写兼容 Chat Completions 的 API 地址、模型和密钥，再主动点击开始；选中文字或普通复制不会自动发给接口。
- 标签过滤在本机运行，可选择质量词、角色外貌、提示词字段、自然语句并编辑自定义词；LoRA 片段独立排除。
- 面板可切换置顶。请求可取消；关闭面板清空本次文字及结果。实际请求内容会交给所配置的服务商。

## 从源码运行与构建

开发和完整测试建议 Windows x64、Node.js 22.4+（打包实机测试使用全局 WebSocket）、npm、Windows PowerShell。本次验证使用 Node.js 24.16.0。Electron 固定为 32.2.0 以保持原包一致。

~~~powershell
npm ci
npm run check
npm test
npm start
~~~

构建时自动重建浏览器脚本、检查源码及基线哈希、执行逻辑测试，再生成免安装目录及 ZIP：

~~~powershell
npm run build:portable
npm run test:portable
~~~

产物在 release/，构建信息见 release/latest-build.json。已存在的发行目录不会覆盖，会添加时间戳。ZIP 的文档或构建信息变化会改变整包哈希；运行代码及媒体必须与基线相同。

## 项目结构

- assets/：运行素材和清单；browser/：浏览器用户脚本。
- 根目录 JS / CJS / HTML / PowerShell：桌面主进程、界面、动作、语音和选区读取。
- scripts/：浏览器构建、完整性检查、打包与实机验证；custom2-baseline.json 保存原包指纹。
- tests/：24 组本地逻辑与资源测试；名称以 -live.cjs 结尾的文件需手动在桌面环境运行。
- docs/：当前说明与历史文档；旧版本文档不代表当前功能。

更换素材见 [素材导入](docs/素材导入.md)。本分支的基线检查刻意拒绝运行文件变化；需要开发新功能时应建立新版本并重新验证，不要仅为让测试通过而重写基线哈希。
